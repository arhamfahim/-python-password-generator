# 🔐 Python Password Generator

A simple random password generator built with Python.

## 📌 About

This project generates random passwords based on the length entered by the user.

The generated password can contain:

* Uppercase letters
* Lowercase letters
* Numbers
* Punctuation/symbols

## 🛠️ Technologies

* Python
* `random`
* `string`

## ▶️ How to Run

Make sure Python is installed on your computer.

Run:

```bash
python password_generator.py
```

Then enter the desired password length.

### Example

```text
Enter password length: 12

Password is generated: K7@pQ#91xLm2
```
